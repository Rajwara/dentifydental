| File | Used for |
|---|---|
| `logo.webp` | Original logo (gold tooth + DENTIFY), transparent background |
| `logo-header.webp` | Logo resized for the site header (made from `logo.webp`) |
| `favicon.png` | Original favicon artwork (1254 × 1254) |
| `favicon-32.png`, `apple-touch-icon.png`, `/favicon.ico` | Browser tab and phone home-screen icons (made from `favicon.png`) |
| `offer.webp` | "Book a consultation & smile check" card in the Services menu |

To change the logo or icon, upload a new `logo.webp` or `favicon.png` and ask for the resized versions to be regenerated.
