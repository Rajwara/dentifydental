# Newsletter assets

Put everything for the newsletter in this folder: images, banners, the photo for the
"Stay updated with dental care tips" sign-up section, logos, and any files for email campaigns.

Suggested names (JPG, PNG or WebP):

| File name | Size (px) | Use |
|---|---|---|
| `signup-photo.jpg` | 800 × 900 | Photo next to the newsletter sign-up form |
| `signup-background.jpg` | 1600 × 600 | Optional background for the sign-up band |
| `email-header.png` | 1200 × 400 | Header image for newsletter emails |
