# Newsletter assets

These files power the newsletter pop-up that appears on every page once a visitor scrolls 30% of the way down.

| File | Used for |
|---|---|
| `woman_cutout_transparent.png` | Portrait on the right of the pop-up |
| `mail_graphic_cluster_transparent.png` | Envelope and letter graphic |
| `paper_plane_icon.svg` | Paper plane that flies in |
| `email_icon.svg` | Icon inside the email field |
| `arrow_right_icon.svg` | Arrow on the Subscribe button |
| `tooth_icon.svg`, `document_icon.svg`, `star_icon.svg` | Feature icons (Oral Health Tips, Latest Clinic Updates, Exclusive Insights) |
| `top_gold_arc.svg`, `bottom_gold_wave.svg` | Gold lines (drawn inline in the page so they can animate) |

The PNG versions of the icons are kept as spares. To replace an image, upload a new file with the same name.
